# 桌面宣传视频

[观看或下载 Aurora Dict 桌面版 60 秒宣传视频](https://github.com/theonegis/Aurora-Dict/releases/download/v2.2.0/aurora-dict_2.2.0_desktop-demo.mp4)

视频演示离线查词、本地 AI 翻译、生词笔记、AI 复习和无账号局域网同步。画面基于产品界面制作，使用 Remotion 模拟输入、点击与页面切换，属于经过加速的功能演示；不代表实际模型推理或网络同步耗时。

- 规格：1920 × 1080，30 fps，60 秒，H.264 / AAC。
- 包含中文字幕和背景音乐，无配音。
- 音乐：[Scaling Up — Ruskerdax](https://opengameart.org/content/scaling-up)，原发布页标注 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。
- 未使用 YouGlish、33台词或其他第三方影视视频素材。

这里的“无内置广告”指极光字典自身界面；移动端外部视频服务的内容与服务规则由其提供方决定。桌面端不包含视频例句功能。

视频以 GitHub 附件和 Release 成片发布，不上传移动端源码或视频制作工程。
